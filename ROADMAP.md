# Learning Roadmap

## Phase 1 — Programming foundations

**Modules 00–04**: setup, program structure, values, input/output, and expressions.

Milestone: write small programs from a blank file without copying an example.

## Phase 2 — Control flow and problem solving

**Modules 05–07**: conditions, loops, and functions.

Milestone: solve problems involving decisions, repetition, and decomposition.

## Phase 3 — Collections and text

**Modules 08–09**: arrays, matrices, and strings.

Milestone: traverse, search, transform, and validate collections.

## Phase 4 — Memory

**Modules 10–12**: pointers, pointer/array relationships, and dynamic memory.

Milestone: explain an address, a pointer, dereferencing, stack/heap, and ownership in your own words.

## Phase 5 — Data modeling and persistence

**Modules 13–15**: structures, unions/enums, and files.

Milestone: build a small file-backed program using structured records.

## Phase 6 — Real C projects

**Modules 16–20**: headers, debugging, bitwise operations, CLI arguments, and intermediate C.

Milestone: build a multi-file command-line program with clean interfaces.

## Phase 7 — DSA bridge

Use [`dsa-preparation/`](dsa-preparation/) to learn complexity, strengthen searching/sorting/recursion, and prepare for linked lists.

### Suggested pace

- 60–90 minutes/day: about 10–14 weeks
- 2 hours/day: about 7–10 weeks
- Faster is not automatically better. Skipping exercises creates the illusion of progress, which is one of education's more reliable scams.
